# Edonsoft Development Framework_x64（占位）

本目录**未随本仓库分发**，仅作占位说明。

## 内容
Edonsoft 开发框架（64 位）本地副本：`EdonSoft Development Framework.accdb`（主库）、`Data.accdb`、`edonsoftCore.accde`（编译核心）、`edonsoft-docs/`（框架官方文档）、`appsettings.json`、`assets/`。

## 官方来源
- 官网：<http://www.edonsoft.com/>
- 框架帮助文档：<http://www.edonsoft.com/access-framework-help.aspx>

## 在技能中的用途
作为 Access 快速开发的现成底座之一（本技能两大底座：Edonsoft 框架 + 盟威平台），提供表/窗体/菜单/权限等基础组件与官方文档，供业务系统开发复用。
