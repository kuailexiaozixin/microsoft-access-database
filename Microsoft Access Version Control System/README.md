# Microsoft Access Version Control System（占位）

本目录**未随本仓库分发**，仅作占位说明。

## 内容
Version Control System 加载项安装产物（安装位置即运行位置，技能内自包含）：`Version Control.accda`（加载项本体）、`MSAccessVCSLib_win64.dll`（x64 COM 库）、`Ribbon.json` / `Ribbon.xml`（功能区定义）、`Worker.vbs`（辅助脚本）。

## 官方来源
- 加载项官方仓库：<https://github.com/joyfullservice/msaccess-vcs-addin>
- Release 下载：<https://github.com/joyfullservice/msaccess-vcs-addin/releases>

## 在技能中的用途
由 `Version_Control_v5.0.1/` 安装包安装至技能内形成；配合 `msaccess-vcs-mcp/` 实现 Access 数据库的文本源导出/构建与全生命周期版本控制。
