# Version_Control_v5.0.1（占位）

本目录**未随本仓库分发**，仅作占位说明。

## 内容
VCS（Version Control System for Microsoft Access）v5.0.1 官方安装包：`Version Control.accda`。运行安装后把完整插件安装至技能内 `Microsoft Access Version Control System/`（安装位置即运行位置，技能内自包含、不注册到其他位置）。

## 官方来源
- 加载项官方仓库：<https://github.com/joyfullservice/msaccess-vcs-addin>
- Release 下载（v5.0.1）：<https://github.com/joyfullservice/msaccess-vcs-addin/releases>

## 在技能中的用途
VCS 插件安装程序；安装后由 `msaccess-vcs-addin/`（源码）与 `Microsoft Access Version Control System/`（安装产物）共同构成技能版本控制三通道中的加载项通道。
