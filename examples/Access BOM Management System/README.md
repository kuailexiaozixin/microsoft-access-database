## 中文

### 项目简介

这是一个基于 Microsoft Access 开发的 BOM（Bill of Materials，物料清单）管理系统，用于管理产品的物料结构和组成关系。

### 功能特性

- **物料清单管理**：支持多级 BOM 结构的创建和维护
- **树形视图**：直观的树形结构展示产品组成关系
- **数据管理**：完整的物料信息录入、查询和修改功能
- **关系维护**：灵活的父子级物料关系管理

### 文件说明

- `BOM.accdb` - Access 2007+ 格式的数据库文件（主要版本）
- `BOM.mdb` - Access 2003 格式的数据库文件（兼容版本）
- `treeview.accdb` - 树形视图演示数据库

### 使用要求

- Microsoft Access 2007 或更高版本（推荐使用 .accdb 文件）
- Microsoft Access 2003（可使用 .mdb 文件）

### 使用方法

1. 下载对应版本的数据库文件
2. 使用 Microsoft Access 打开数据库文件
3. 根据界面提示进行物料和 BOM 数据的录入与管理

## English

### Introduction

A comprehensive BOM (Bill of Materials) management system developed with Microsoft Access, designed to efficiently manage product material structures and component relationships.

### Features

- **BOM Management**: Support for creating and maintaining multi-level BOM structures
- **Tree View**: Intuitive tree structure display for visualizing product composition hierarchies
- **Data Management**: Complete material information entry, query, and modification capabilities
- **Relationship Maintenance**: Flexible parent-child material relationship management

### File Description

- `BOM.accdb` - Access 2007+ format database file (main version)
- `BOM.mdb` - Access 2003 format database file (compatible version)
- `treeview.accdb` - Tree view demonstration database

### Requirements

- Microsoft Access 2007 or higher (recommended for .accdb files)
- Microsoft Access 2003 (for .mdb files)

### Getting Started

1. Download the appropriate version of the database file
2. Open the database file with Microsoft Access
3. Follow the interface prompts to enter and manage materials and BOM data
