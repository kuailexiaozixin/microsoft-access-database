# Access DatePicker（占位）

本目录来自开源仓库，**未随本仓库分发**，仅作占位说明。

## 内容
纯 VBA 实现的 Access 日期选择器 / 年月选择器（零外部依赖、一键部署）：`Module_DatePicker.bas` / `Module_YearMonthPicker.bas`（模块）+ `DatePicker.accdb`（演示库）+ 截图与 `使用说明.md`。

## 上游来源
- GitHub：<https://github.com/miaowei2>

## 在技能中的用途
对应工作流**阶段 4（窗体与控件）**的可复用积木：给日期/年月输入框直接配上选择器，免去自己写日历窗体。用法见 `examples/README.md`。
