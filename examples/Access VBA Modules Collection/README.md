# Access VBA Modules Collection（占位）

本目录来自开源仓库，**未随本仓库分发**，仅作占位说明。

## 内容
面向企业级 Access 开发的高频 VBA 模块 / 类集合（AccessDevelop）：自动编号 `basAutoNumStr.bas`、字段校验 `ClsFieldValidator.cls` / `M_ValidationUI.bas`、ADO 执行 `ADOExecute.cls`、VBE 工具 `modVBETools.bas`、导出 Excel/PPT/HTML/图表 `modExportToExcel.bas` / `modExportToPPT.bas` / `modHTMLExport.bas` / `basExportChart.bas` / `modPasteDataToExcel.bas`、翻译 `modAzureTranslator.bas`，另含 `wiki/` 文档。

## 上游来源
- GitHub：<https://github.com/miaowei2>

## 在技能中的用途
跨阶段可复用积木：自动编号（阶段 2）、字段校验 / ADO / VBE 工具（阶段 3 代码库、阶段 4 控件）、导出 Excel/PPT/HTML（阶段 5 报表输出）。用法见 `examples/README.md` 与 `SKILL.md` 对应步骤。
