# Access VBA 常用模块集合 Wiki

欢迎访问 Access VBA 常用模块集合的 Wiki 文档！

## 📖 关于本项目

本项目是一个精心整理的 Microsoft Access VBA 模块集合，包含了日常开发中最常用的功能模块，旨在帮助开发者提高效率、减少重复劳动。所有代码均已在实际项目中验证通过。

### 🔧 按功能分类

#### 数据导出模块
- [modExportToPPT](modExportToPPT) - PowerPoint 导出
- [modExportToExcel](modExportToExcel) - Excel 导出
- [modPasteDataToExcel](modPasteDataToExcel) - 智能 Excel 粘贴
- [basExportChart](basExportChart) - 图表导出
- [modHTMLExport](modHTMLExport) - HTML 导出

#### 数据处理模块
- [basAutoNumStr](basAutoNumStr) - 智能自动编号
- [ADOExecute](ADOExecute) - ADO 数据库操作

#### 开发工具模块
- [modVBETools](modVBETools) - VBA 代码开发工具
- [modAzureTranslator](modAzureTranslator) - Azure 翻译服务

#### 验证模块
- [ClsFieldValidator](ClsFieldValidator) - 字段验证类
- [M_ValidationUI](M_ValidationUI) - 验证界面辅助

## 📦 系统要求

- **Microsoft Access** 2010 或更高版本
- **Windows** 操作系统
- 部分模块需要额外的对象库引用（详见各模块文档）
