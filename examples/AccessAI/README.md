# AccessAI（占位）

本目录来自开源仓库，**未随本仓库分发**，仅作占位说明。

## 内容
Access LLM Toolkit（开源 VBA 工具库，即 AccessAI）：`AI.accdb`（演示库）+ `JsonConverter.bas` / `Module_Markdown.bas`（核心模块）+ 示例图与使用文档（另含 `AI.rar` 打包件、`LICENSE`）。能力：`CreateAIForm` 一键建窗体、流式输出、对话历史持久化、Access SQL 助手、TXT/CSV/Word/Excel/PDF 文档问答、API Key 用 Windows DPAPI 加密。

## 上游来源
- GitHub：<https://github.com/miaowei2/accessAI>

## 在技能中的用途
对应工作流**阶段 6（AI 接入）**的可复用积木：在 Access 内调用大模型，把 AI 能力接进业务系统。用法见 `examples/README.md` 与 `SKILL.md` 阶段 6。
